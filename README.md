A single 278-character one-line one-star review, written in the voice of a houseplant about the human who owns it: a drainage-hole grievance with a counted watering record (four times since January, twice with leftover coffee), roots filing a formal complaint from their puddle, and a newest leaf that came out already apologising to the light. `main.py` (pure Python 3.13 stdlib, deterministic, no network) writes exactly that one line to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/sap-out python3 main.py && cat /tmp/sap-out/entry.txt
```
